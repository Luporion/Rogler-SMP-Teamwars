# Rogler Core v0.6.6 – FTB membership / Core Guard hotfix

This version repairs the ability of existing legitimate FTB party members to edit their own Core-protected blocks, even when the party exceeds TeamWars' *advisory* configured member cap. Owner/team UUIDs remain unchanged. See `docs/releases/v0.6.6.md`.

The server still requires a real FTB party membership. TeamWars does not force add members or grant rights to unaffiliated users. NeoForge CI + dedicated runtime test remain mandatory.
