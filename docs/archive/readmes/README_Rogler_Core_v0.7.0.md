# Rogler Core v0.7.0 - Map Privacy Source Candidate

This version extends **v0.6.6** (patch applies directly to **v0.6.5** and includes v0.6.6 changes), preserving existing Core IDs, team ownership, inventories and FTB Claims.

Included: server-side Xaero fair-play login enforcement, fail-closed map privacy policy, server-side per-player exploration provenance persisted atomically, `/rogler map status` and `/rogler map zone`, Xaero server-profile deployment templates.

**Not complete:** team-shared exploration displayed on Xaero (including revocation), long-distance teammate markers, automatic two-way local FTB/Xaero waypoints, on-map zone circles. Read [release notes](../../releases/v0.7.0.md) for testing and installation. Java-only checks are not equivalent to a NeoForge Minecraft build.
