# Mod Requirements – v0.5.1

Required (unchanged): Minecraft 1.21.1, NeoForge 21.1.249, FTB Teams 2101.1.11, FTB Chunks 2101.1.22, compatible FTB Library 2101.1.37, and exactly one Rogler TeamWars v0.5.1 JAR after CI.

Optional (not new prerequisites): Applied Energistics 2 (for a neighboring FE Energy Acceptor; no ME grid integration), Create (kinetic source NOT yet implemented), Sophisticated Core/Backpacks (upgrade adapter NOT yet implemented), Sable/Create Aeronautics (mobile base NOT implemented).

**New third-party mods required: NONE.** `Capabilities.EnergyStorage.BLOCK` is provided by NeoForge itself. Client and server must both have matching TeamWars JAR for in-game test. Do not combine old 0.5.0 and new 0.5.1 JAR.
