# v0.1.0 — FTB Team Mirror + Nametag Privacy (release candidate)

**Date:** 2026-10-10. **Status:** SOURCE IMPLEMENTED; REAL NEOFORGE BUILD + RUNTIME UNVERIFIED.

## Scope & restrictions

- Server authoritative: existing FTB Teams 2101.1.11 owns parties, members, invites, kicks, rename. TeamWars does NOT write FTB data.
- On login and each configurable refresh, TeamWars reads FTB party for online players and projects into vanilla scoreboard teams. Only teammates see nametags, if unmodified by other mods.
- Invalid/oversized FTB team membership -> isolated nametag teams until corrected. `max_party_size` MUST also be configured in FTB's server config.
- Teamnames currently mirror free FTB names; **paid rename fee is not implemented**, use admin moderation.
- Number of parties is only detected among online players, not globally enforced.
- Command status/own team/admin resync/admin config reload; config invalid -> safe defaults + log warning.
- FTB Teams internal read API used via reflection; actual signature compatibility against 2101.1.11 must be proven on a real server. If broken, expected fail-closed result: solo nametags and warning, not false team sharing.
- Other scoreboard-using mods may conflict because Minecraft assigns each player to only ONE scoreboard team. Test modpack compatibility before production.

## Rollback

1. Back up the whole world (including scoreboard.dat, FTB Teams data, TeamWars config) before loading the JAR.
2. If any nametag conflicts or errors occur, remove the TeamWars v0.1 JAR **from staging** and restart; FTB Teams itself remains the membership authority and retains its own team data.
3. Vanilla scoreboard teams with prefix `rt`/`rs` may remain in `scoreboard.dat` after mod removal. Clean up only the exact owned teams after inspection; do not wipe the entire scoreboard or FTB database.
