# Rogler TeamWars v0.2.2 – Source candidate

**Datum:** 2026-10-11 | **Ziel:** Minecraft 1.21.1, NeoForge 21.1.249, FTB Teams 2101.1.11.

## Änderungen
- `Shift + Rechtsklick` auf den platzierten eigenen Basis-Kern: kontrolliertes Einpacken (kein Mining), neues signiertes Kern-Item, alter Token ungültig.
- `/teamwars base pack` als Fallback, nur in 8 Blöcken Nähe und beim eigenen Teamkern.
- Inventar-voll-Blockade, falsches Team und falscher Standort werden verweigert. Transportzeit wird NICHT zurückgesetzt.
- `/teamwars admin salvagemissing <Spieler>` nur nach Prüfung eines fehlenden physischen Kerns in geladenem Chunk; `/teamwars base recover` für Teammitglieder.
- Zusätzliche Tests und Log-Protokolle.

## Verifiziert
- Java Core-Tests (Zählung siehe Terminal bei lokaler Ausführung), No-Minecraft-Regeln.
- Der Patch entspricht den originalen Quellcode-Blobs des v0.2.1-GitHub-Branches für alle beteiligten Implementierungsdateien.

## Noch offen (nicht als stabil bezeichnen)
- NeoForge-CI-Build, Login/Client-Rechtsklick, 2-Spieler-Test, Save/Load im Minecraft-Profil.
- Kernblock-Schutz gegen alle modded World-Edits und Crash-Transaktionen.
- Claims, Grace, Raid-Blockierung, Aufklärung, Markt, Schiff.

## Benötigte Mods
**Keine neuen Drittanbieter-Mods:** Minecraft 1.21.1 + NeoForge 21.1.249, FTB Teams 2101.1.11 mit kompatibler FTB Library, Rogler TeamWars **v0.2.2** statt v0.2.1. FTB Chunks ist bereits vorhanden, aber die Core-Integration kommt später.

## Installation
1. Backup der Testwelt.
2. Patch auf `fix/v0.2.1-core-rescue` als neue Branch `feat/v0.2.2-core-relocation` anwenden.
3. `scripts/test-core.ps1`, Push, `scripts/watch-actions.ps1`.
4. Nach erfolgreicher CI ausschließlich die neue JAR im DEV-Profil installieren (alte JAR entfernen).
5. Zwei Teammitglieder und einen Gegner testen. Nicht ohne Abnahmetests auf den Produktionsserver bringen.
