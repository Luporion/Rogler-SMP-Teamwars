# Rogler TeamWars v0.5.4 — Create drive sync, 27-slot inventory, paid books

**Base:** GitHub commit `731c0bd1` (`feat/v0.5.3-update`) — v0.5.3, green CI and user-verified GUI, upgrades, AE2 and FE transfer.
**Status:** Source and offline Java checks only; **NeoForge/CI/ingame v0.5.4 not yet verified**.

## Fixes

1. **Create kinetic drive:** Fix server/client disagreement when `getGeneratedSpeed()` accessed on client, where previous code returned 0 because team SavedData only exists server-side. Sync `TeamWarsDriveEnabled` through Create BlockEntity tag and read it before Create's kinetic data. The create goggles should no longer say 0 SU when the real Create network has 256 SU. Add a *bounded* once-per-20-server-tick recovery check for missing speed after purchasing the upgrade in an already-placed core, without requiring pickup/replacement; does not force-load chunks, and does not run on inactive/unplaced cores. Existing 16 RPM / 256 SU balance unchanged.
2. **Team inventory** expanded from 9 to **27 slots** (one vanilla chest). Existing 0..8 slots are preserved under the SAME SavedData key and NBT schema; new slots 9..26 begin empty. GUI bottom area reflows by 2 extra rows and shift-click uses `SLOTS` instead of hardcoded indices. Core relocation, recovery and admin adoption use the new 27-slot count. **Backup world before migration.** Do not downgrade to older versions after storing anything in slots 9..26: an old version may silently ignore them.
3. **Manuals:** `/teamwars guide give <modid>` and the GUI's guide button now exchange **one actual `minecraft:book`** for one registered handbook. No book -> no issue; no room -> no consumption; duplicate identical manual carried -> refuse as before. Still not a full Patchouli integration and still uses existing heuristic manual discovery. No independent currency or unlimited free duplication.
