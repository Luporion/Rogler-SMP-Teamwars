# v0.5.2 compile hotfix — Core BlockEntity deferred factory

Base commit: `ebd00b64`, branch `feat/v0.5.2-update`.

## Root cause
GitHub Actions Run `38405617166` failed during `:compileJava`: `BaseCoreRegistries.java:28: error: self-reference in initializer`. The factory passed to `BlockEntityType.Builder.of` tried to reference `CORE_BE` while initializing `CORE_BE` itself.

## Fix
Replace the inline lambda by a method reference to `BaseCoreRegistries.createCoreEntity(BlockPos,BlockState)`. That factory accesses `CORE_BE.get()` only when Minecraft creates an instance, after deferred registration has completed. The block registry names and entity types are unchanged; the fix adds no world migration or new dependency.
