# TeamWars v0.3.1 — Orphan recovery, Creative ghosts, early block protection

Status: source candidate; Java 21 core tests run locally. NeoForge compile and in-game two-team tests PENDING.

## Changes
- An admin can list registered cores whose FTB party UUID no longer exists (`/teamwars admin orphanlist`), distinguish MISSING vs FTB API UNAVAILABLE, and explicitly adopt an orphan for a NEW party (`/teamwars admin adoptcore <oldPartyUUID> <newTeamPlayer>`).
- Only confirmed MISSING teams may be adopted. This is deliberately NOT automatic name-based matching. The receiving party must not already have a core. A newly issued replacement token revokes any old bearer; ISSUED orphan transfers to ESCROW, PLACED stays at verified physical location. Old grace period carries over without reset. If physical block is missing, transfers via ESCROW. If TeamWars-managed FTB claim bookkeeping exists, adoption refuses until separately audited; no automated unsafe unclaim.
- Early protection on `LeftClickBlock` at HIGHEST priority, break-speed reduction and HIGHEST `BreakEvent` handling before physics hooks. Tree Physics interactions that bypass these events are NOT yet proven blocked; needs real world test with THT/treephysics compatibility.
- Once per server second, server inventory reconciliation removes stale unique core items whose token already belongs to a PLACED core. Creative inventory broadcasts are sent. This does not ban every client-side visual ghost frame; repeat tests with Creative packet reinsertion.
- FTB Claims remain opt-in (auto_ftb_claims=false). Raids stay disabled; no auto chunkloading yet.

## IMPORTANT limitation: FTB party lifecycle
FTB Teams 2101.1.11 deletes a party when its last member leaves. v0.3.1 **does not** stop FTB itself deleting parties or affect unrelated party membership. An orphan is kept protected until a deliberate admin adoption. Configure FTB Ranks/permissions to restrict party leave or provide a future FTB API override if forbidding deletion is required. Never assign a base simply by reusing a displayed team name.

## Required modpack dependencies
Minecraft 1.21.1, NeoForge 21.1.249, FTB Teams 2101.1.11, FTB Library 2101.1.37, FTB Chunks 2101.1.22; no new dependency from v0.3.0.
