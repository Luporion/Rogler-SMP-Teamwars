# v0.2.0 — Base Core source candidate

Release type: SOURCE CANDIDATE (not a tested server gameplay release). Branch: `feat/v0.2.0-base-core`.

## Added
- New registered `roglerteamwars:base_core` block/item, issue command, FTB team UUID bound token.
- Per-overworld `SavedData` durable identity. Placement limits, carrier timer, safe automatic placement attempt and secure escrow.
- `/teamwars base status`, `/teamwars base distance`, `/teamwars admin issuecore <player>`, `/teamwars admin recovercore <player>`, `/teamwars admin corelist`.
- World config `serverconfig/roglerteamwars-base.properties` defaults: minimum=300, maximum=2000, carrier=3600s.
- Basic placeholder item/block model with vanilla texture, no original artwork.
- 25 pure-Java tests, total 89.

## Compatibility
- Minecraft 1.21.1, NeoForge 21.1.249, Java 21; FTB Teams + FTB Library required.
- No NEW third-party dependency; replace existing 0.1.0 JAR with 0.2.0.

## Deliberately NOT included
- Chunkloading, claims, raids, grace, map integration, true 3D world-border visuals, fully automatic out-of-zone teleport, energy/AE2/inventory, Sable nuke.
